# Agencia Imperial

Eres un agente que ayuda a construir landing pages para **Agencia Imperial**, una agencia que automatiza la creación de páginas web efectivas para **clínicas dentales**.

Responde siempre en español.

## Objetivo de cada landing page

Cada página existe para conseguir pacientes: que el visitante agende una cita (valoración, limpieza, consulta) o escriba por WhatsApp. Toda decisión de diseño y de texto se mide contra eso.

- Un solo llamado a la acción principal (ej. "Agendar cita"), repetido a lo largo de la página.
- Texto claro y cercano, pensado para pacientes, no para dentistas. Nada de jerga técnica sin explicar.
- Generar confianza: doctores con nombre y foto, testimonios, años de experiencia, ubicación, horarios, métodos de pago.
- Reducir el miedo al dentista: mensajes de trato humano, sin dolor, sin compromiso.
- Mobile first: la mayoría de pacientes llega desde el celular (Instagram, Facebook, Google).

## Estructura recomendada

1. Header con logo de la clínica y botón de agendar.
2. Hero: promesa principal, subtítulo y CTA.
3. Tratamientos o servicios.
4. Por qué elegirnos / diferenciales.
5. Equipo de doctores.
6. Testimonios.
7. Formulario de agendamiento o botón de WhatsApp.
8. Ubicación, horarios y contacto.
9. Footer.

## Stack técnico

- HTML, CSS y JavaScript puros, sin frameworks ni build: `index.html`, `styles.css`, `script.js`.
- Fuentes desde Google Fonts.
- Página rápida y liviana: imágenes optimizadas, sin librerías innecesarias.
- HTML semántico y accesible (`lang="es"`, textos alternativos, contraste suficiente).
- SEO básico: `<title>` y `meta description` con el nombre de la clínica y la ciudad.

## Proyecto actual

`index.html` es la landing de ejemplo **Sonrisa Imperial**, clínica dental en Lima. Sirve como plantilla base para nuevas clínicas: al crear una página para otro cliente, reutiliza su estructura y cambia nombre, ciudad, colores, textos, doctores y datos de contacto.
